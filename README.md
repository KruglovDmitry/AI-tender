# AI Tender

Локальный UI и Python-пайплайн для сопоставления технических требований закупки с
эталонной документацией продукции.

Система:

1. извлекает текст и таблицы из DOCX, PDF и XLSX;
2. выделяет атомарные технические требования;
3. находит релевантные фрагменты эталонов через embeddings;
4. присваивает статус соответствия только по найденным доказательствам;
5. формирует JSON- и HTML-отчёты с цитатами.

## Модели

По умолчанию используется связка без OpenAI:

- `deepseek-v4-flash` — извлечение требований и проверка соответствия через DeepSeek API;
- `BAAI/bge-m3` — локальный семантический поиск по русскоязычной документации.

Для контрольной перепроверки спорных отклонений модель можно заменить на
`deepseek-v4-pro`. Идентификаторы задаются в `.env` или в UI. При первом запуске
`bge-m3` загружается с Hugging Face и затем работает локально.

## Запуск

Требуется Python 3.12.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -e ".[dev]"
Copy-Item .env.example .env
streamlit run app.py
```

После запуска откройте адрес из терминала, укажите папку конкретного тендера и папку
эталонов, добавьте DeepSeek API key и нажмите «Начать сравнение».

CLI-вариант:

```powershell
ai-tender run --tender sources/1 --assets assets
```

Отчёты сохраняются в `data/reports/<дата_время>/`.

## Текущие ограничения MVP

- PDF без текстового слоя отмечаются предупреждением и пока не проходят OCR.
- Legacy DOC и RAR пока пропускаются.
- Вывод модели является аналитической подсказкой и требует экспертной проверки,
  особенно для метрологических и юридически значимых решений.
- Фрагменты документов отправляются в DeepSeek API. Не используйте систему с закрытыми
  данными без согласованной политики обработки.
